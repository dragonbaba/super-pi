# 连续请求的缓存用量

整场命中率会掩盖每轮持续产生的固定成本。`/session` 现在同时显示当前分支最近一段连续请求的未命中输入 P50、P95，以及相邻请求总输入净增长 P50。按最近秩取整。输入包含普通输入、缓存读取和缓存写入，未命中包含普通输入和缓存写入。净增长允许为负。

首轮仅提供比较基线。压缩、分支摘要、显式切模、供应商/API/请求模型或已知响应模型变化、失败及缺少有效用量都会截断比较。整场账单统计仍包括其他分支。指标使用已记录用量，无法从长度判断历史内容是否完全相同或服务端为何未命中。

离线夹具中三个连续请求的未命中输入为 2,100、1,500、3,000 token，输入净增长分别为 1,100、−600、1,000。统计在用户执行命令时计算，不保存提示正文。运行 `node --import tsx --test tests/cache-overlap.test.ts` 检查统计、边界和终端显示。
